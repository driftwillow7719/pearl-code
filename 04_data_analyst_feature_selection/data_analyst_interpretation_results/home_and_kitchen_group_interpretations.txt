HOME AND KITCHEN POPULARITY-TREND SEGMENTS: GROUP INTERPRETATIONS AND PAIRWISE COMPARISONS
============================================================================================

A note on interpretation before the group-by-group material: within each group, "correlation with
the outcome" measures how strongly a candidate feature is associated with an item ending up in that
specific (popularity-cluster, direction) combination rather than in one of the other combinations
sharing the same popularity cluster and history-depth bucket. A positive correlation means higher
values of the feature go with this group's outcome; negative means lower values do. Separately, several
groups' profiles report the typical size of the historical popularity change itself (e.g., "items in
this group changed by X"). That figure describes what already happened to labeled training items and
is never a usable input feature for a new, unlabeled item — it is repeated below only where the source
material reports it, and always with that same caveat attached. Statistical claims about item_age's
relationship to other features are held to a fixed bar throughout this document: a relationship is
treated as real only when it reaches p < 0.01 and an absolute correlation of at least 0.10; anything
reaching significance only through a very large sample while staying under that magnitude is called out
as statistically detectable but practically negligible, not as a meaningful pattern.


================================================================================
GROUP: high_popular / decrease
================================================================================

GROUP DEFINITION
This group covers items that were highly popular and then declined (n=362). Latest popularity value
typically sits at 13 (middle 50%: 10-22; full range 7-146). Item age typically 2 months (middle 50%:
0-14). Across the observed trend, the low point typically bottoms at 0 (middle 50%: 0-1; up to 37 at
the extreme) and the high point typically reaches 15 (middle 50%: 10-25; up to 164). Volatility
averages around 4.24 (middle 50%: 2.92-7; up to 67.2 at the extreme), with a net change of +9 in trend
value from start to end. The peak in the trend typically occurred right at the latest observation
(middle 50%: 0-2 months before it). Momentum typically reads 0.388 (middle 50%: 0-1.1; full range
-1.82 to 3), but this is based on only 227 of the 362 items — the other 135 had no momentum value
because they had only a single real trend point. Historically, items that reached this outcome changed
by -4 in popularity value from their pre-outcome (latest) value to the final observed value (middle
50%: -9 to -2; full range -124 to -1) — this describes what already happened to labeled training items
and is not a feature that can be computed for a new, unlabeled item. None of the 362 items were debut
items; 135 of the 362 (37%) had only one real historical trend point, which matters if a query item
itself has thin history.

DATA RELIABILITY NOTE
The group total (n=362) is a moderate sample. Within it, the recent_single_point sub-population is 135
items, recent_multi_point only 61, and maturing 166 — the recent_multi_point trend figures in
particular rest on a fairly small true count and should be treated with some caution. The
feature-vs-outcome correlations reported below for each bucket are computed over a larger sample (548
in recent_single_point, 192 in recent_multi_point, 731 in maturing) because they test how well each
feature separates "decrease" from this popularity cluster's other two directions using every
high_popular item in that bucket, not just the 362 decrease members — those coefficients are
well-powered even where the group's own descriptive counts are thin.

KEY FEATURE-OUTCOME RELATIONSHIPS
In the single-observation bucket, only two features can be tested at all, since anything requiring a
second trend point is structurally undefined here: latest popularity value is a strong signal for this
outcome (r=0.668, p=5.1e-72, n=548 — higher current popularity favors ending up in this
high-popularity-decline group), and embed_similarity adds a much weaker but still real signal in the
same direction (r=0.098, p=0.022, n=548). Because so few features are usable in this bucket, that weak
embed_similarity reading is worth keeping rather than discarding — it's essentially the only other
lever available for single-point items here.
Once an item has two or more trend points (recent_multi_point), the picture is dominated by trend
shape: latest popularity value remains the strongest predictor (r=0.716, p=1.7e-31, n=192), but
trend_max is nearly as strong (r=0.742, p=7.1e-35) and trend_volatility close behind (r=0.667,
p=4.4e-26) — higher recent peaks and choppier trends both favor a subsequent decline from a
high-popularity position. trend_min (r=0.480, p=1.9e-12) and trend_overall_change (r=0.441,
p=1.5e-10) point the same direction more moderately, latest_momentum contributes a smaller positive
signal (r=0.311, p=1.2e-5), time_since_peak is weaker and runs the opposite way (r=-0.294, p=3.5e-5,
meaning a more recent peak favors this decline outcome), and embed_similarity is only marginally useful
here (r=0.156, p=0.031).
In the maturing bucket, latest popularity value again leads (r=0.595, p=2.4e-71, n=731), with
trend_overall_change (r=0.497, p=9.5e-47), trend_volatility (r=0.479, p=3.0e-43) and trend_max
(r=0.473, p=5.3e-42) all substantial and moving in the same direction — items with a higher recent
value, a larger overall upward-then-down swing, and more erratic trends are the ones landing in this
outcome. time_since_peak is a moderate, oppositely-signed signal (r=-0.282, p=8.8e-15: a peak that
happened longer ago works against this outcome), latest_momentum is a smaller positive signal
(r=0.211, p=8.0e-9), and trend_min is only marginally useful (r=0.078, p=0.035); embed_similarity is
not a real signal in this bucket (r=0.052, p=0.16).

ITEM_AGE-LINKED PATTERNS
Item age shows one of the broadest sets of real relationships to other features seen in this dataset
for this group, evaluated pooled across the group's history-depth buckets (n=227 for trend-derived
features, n=362 for latest_pop_value and embed_similarity, since trend features require real trend
history). Older items in this group have a markedly lower trend_min (r=-0.655, p=3.3e-29), lower
trend_volatility (r=-0.418, p=5.1e-11), a peak that occurred longer ago (time_since_peak r=0.344,
p=1.0e-7), a lower latest popularity value (r=-0.339, p=3.4e-11), a lower trend_max (r=-0.336,
p=2.2e-7), and lower momentum (r=-0.270, p=3.6e-5) — all six clear the bar for a real relationship.
embed_similarity (r=-0.060, p=0.25) and trend_overall_change (r=0.039, p=0.56) show no real
relationship with item_age here. Because latest_pop_value, trend_volatility, and trend_max are also
among the strongest outcome predictors in this group's key-feature relationships above, these
item_age links deserve real weight: for an older item, several of the features that most strongly
drive this outcome will themselves already be pushed lower by age, so age should be treated as a
meaningful conditioning factor when reading those features for this group, not just a side note.
trend_min's very strong age relationship (r=-0.655, the single strongest item_age link found anywhere
in this group) stands out as a near-dominant pattern independent of its outcome relevance and is worth
flagging on its own.

ONE-LINE TAKEAWAY
Latest popularity value is this group's most consistently strong and reliable feature across every
bucket, reinforced by trend_max and trend_volatility once real trend history exists, but all three
should be read with the knowledge that older items in this group are systematically pulled toward
lower values on exactly these features.


================================================================================
GROUP: high_popular / increase
================================================================================

GROUP DEFINITION
This group covers items that were highly popular and continued to increase (n=1,050 non-debut items;
1,510 including debut items — see the separate debut discussion below). Latest popularity value
typically 3 (middle 50%: 2-6; full range 0-137). Item age typically 4 months (middle 50%: 0-14). The
trend's low point typically sits at 0 (middle 50%: 0-1; up to 12) and its high point typically at 6
(middle 50%: 4-9; up to 59). Volatility averages 1.71 (middle 50%: 1.05-2.6; up to 24.1), with a net
change of +2 across the trend. The peak typically occurred 3 months before the latest observation
(middle 50%: 1-6). Momentum typically reads 0 (middle 50%: -0.352 to 0.693; full range -2.64 to 3),
based on only 654 of the 1,050 non-debut items — the other 396 had no momentum value due to a single
trend point. Historically, items reaching this outcome changed by +5 in popularity value from their
pre-outcome value to the final observed value (middle 50%: +3 to +8; full range +1 to +100) — this
describes labeled training items already known to belong to the group and is not computable for a new
item. Of the 1,510 total items reaching this outcome, 460 (30%) were debut items with no trend history
at all; of the 1,050 non-debut items, 396 (38%) had only a single real trend point.

DATA RELIABILITY NOTE
The non-debut population (1,050) is large and well-powered overall, though the recent_multi_point
bucket's true membership (1,466 per the correlation study's member counts, larger than the 1,050
figure because that count spans multiple sources) and maturing bucket (6,265) dwarf the
recent_single_point bucket's contribution to trend-based descriptive stats. As with the other groups,
the feature-vs-outcome correlations below are computed against the full high_popular population sharing
each bucket (548/192/731), which is a much larger and better-powered sample than the group's own
counts. The 460 debut items are excluded entirely from this group's own descriptive and correlational
figures and are handled separately below.

KEY FEATURE-OUTCOME RELATIONSHIPS
In the single-point bucket, only latest_pop_value is a real signal, and it runs opposite to this
group's typical direction of change: lower current popularity favors this outcome (r=-0.674,
p=1.1e-73, n=548) — intuitively, an item with more room to grow is more likely to be the one that
increases further. embed_similarity is not a real signal here (r=-0.122, p=0.0042, which is
statistically significant but weak and, given it is the only other candidate available, worth
flagging as the second-best option in this sparse bucket despite its modest size).
Once real trend history exists (recent_multi_point), the same latest_pop_value relationship becomes
far stronger and remains the dominant signal (r=-0.727, p=7.2e-33, n=192), but several trend features
are close behind: trend_max is nearly as strong (r=-0.752, p=2.9e-36), trend_volatility substantial
(r=-0.677, p=4.3e-27), trend_overall_change moderate (r=-0.466, p=1.0e-11), trend_min moderate
(r=-0.480, p=1.8e-12), and time_since_peak a positive, moderate signal (r=0.319, p=6.6e-6 — a peak
further in the past favors this outcome). latest_momentum contributes a smaller negative signal
(r=-0.308, p=1.4e-5), item_age itself is weakly but genuinely predictive of the outcome in this bucket
(r=0.167, p=0.020), and embed_similarity is not clearly useful here (r=-0.168, p=0.020, right at the
edge of significance and small in magnitude).
In the maturing bucket, latest_pop_value again leads by a wide margin (r=-0.613, p=1.5e-76, n=731),
with trend_overall_change (r=-0.507, p=5.2e-49), trend_max (r=-0.482, p=1.0e-43) and trend_volatility
(r=-0.477, p=9.5e-43) all substantial in the same direction, time_since_peak a smaller positive signal
(r=0.277, p=2.2e-14), and latest_momentum weaker still (r=-0.201, p=4.0e-8). item_age is a marginal
signal here (r=-0.091, p=0.014 — technically outside the p<0.01 bar this document applies elsewhere,
so it should be treated as borderline rather than solid), trend_min is not a real signal (r=-0.070,
p=0.059), and neither is embed_similarity (r=-0.071, p=0.054).

ITEM_AGE-LINKED PATTERNS
Pooled across this group's buckets (n=654 for trend-derived features, n=1,050 for latest_pop_value and
embed_similarity), item_age has a real, positive relationship with time_since_peak (r=0.515,
p=1.4e-45 — older items' peaks sit further in the past, which is close to definitional but still worth
stating), a real negative relationship with trend_min (r=-0.478, p=1.5e-38 — older items have a lower
trend floor), and a real positive relationship with trend_max (r=0.283, p=1.6e-13 — older items also
reach a higher peak). trend_overall_change is weakly but genuinely linked (r=0.184, p=2.3e-6).
latest_momentum shows a real but small negative relationship (r=-0.133, p=6.5e-4), and trend_volatility
clears the bar only marginally (r=0.110, p=0.0049). embed_similarity (r=0.012, p=0.69) and
latest_pop_value (r=0.006, p=0.84) show no real relationship with item_age at all. Because
latest_pop_value — this group's single strongest outcome predictor in every bucket — shows essentially
zero relationship with item_age, that predictor can be read the same way regardless of how old the
item is, which is itself a useful, decision-relevant fact. trend_max and trend_volatility, which are
also top-ranked outcome predictors in the recent_multi_point and maturing buckets, do carry real
item_age relationships and should be interpreted with age in mind: an older item's higher trend_max and
somewhat higher trend_volatility partly reflect its age rather than being independent evidence.
time_since_peak's very strong item_age correlation (r=0.515, the largest in this group) stands out as
a near-mechanical relationship worth flagging on its own, independent of its more modest role as an
outcome predictor.

ONE-LINE TAKEAWAY
Latest popularity value is the clear leading feature for this group in every bucket (lower current
popularity favors continued increase) and is essentially unaffected by item age, making it the most
stable and portable signal to rely on regardless of how much history the query item has.


================================================================================
GROUP: high_popular / stable
================================================================================

GROUP DEFINITION
This is the smallest group in the dataset: items that were highly popular and stayed flat (n=59).
Latest popularity value typically 7 (middle 50%: 6-9; full range 6-20). Item age typically 10 months
(middle 50%: 0-19). The trend's low point typically sits at 0 (middle 50%: 0-1; up to 4) and its high
point typically at 9 (middle 50%: 7-13.8; up to 59). Volatility averages 2.63 (middle 50%: 2.08-3.54;
up to 22.4), with a net trend change of +5. The peak typically occurred 2 months before the latest
observation (middle 50%: 0-3.75). Momentum typically reads 0.144 (middle 50%: -0.17 to 0.66; full
range -1.29 to 1.95), based on only 42 of the 59 items — 17 had no momentum value due to a single trend
point. Historically, items in this group changed by 0 in popularity value from their pre-outcome value
to the final observed value (middle 50%: 0 to 0; full range 0 to 0, i.e. this outcome is close to
definitionally "no change") — this describes labeled training items and is not computable for a new
item. None of the 59 items were debut items; 17 of the 59 (29%) had only a single real trend point.

DATA RELIABILITY NOTE
This is by a wide margin the sparsest group in the dataset. Its true sub-bucket counts are tiny —
recent_single_point 17, recent_multi_point only 5, maturing 37 — so every correlation and typical-value
claim below should be read as anecdotal at best in the recent_multi_point bucket especially, and only
moderately more trustworthy in maturing. The feature-vs-outcome correlations are computed against the
much larger shared high_popular sample per bucket (548/192/731 respectively), so those coefficients
themselves are statistically well-powered even though this group's own share of that sample is small;
what's unreliable is not the correlation estimate but how representative this group's 59 members are of
"typical" values.

KEY FEATURE-OUTCOME RELATIONSHIPS
This is a weak-signal group throughout, and in a group this data-sparse, even modest correlations are
the most useful evidence available. In the single-point bucket, neither latest_pop_value (r=0.080,
p=0.062) nor embed_similarity (r=0.073, p=0.089) reaches significance — there is no real
feature-outcome signal available at all for single-observation items in this group. In
recent_multi_point, nothing clears significance either (all p-values above 0.17), so no usable feature
signal exists in that bucket. Only in maturing does anything separate meaningfully: latest_pop_value is
the strongest available signal, though still modest (r=0.114, p=0.0020, n=731), followed by
trend_overall_change (r=0.087, p=0.018) and trend_max (r=0.080, p=0.030) — both weak but real, and, in
a group this sparse on signal, worth reporting as the leading evidence rather than dismissing as
negligible. Nothing else in the maturing bucket reaches significance.

ITEM_AGE-LINKED PATTERNS
Pooled across buckets, only one feature clears the bar for a real item_age relationship: trend_min
(r=-0.648, p=3.4e-6), and this is based on just 42 items, so while the relationship is statistically
real it should be treated with real caution given the tiny underlying sample — older items in this
group have a markedly lower trend floor. Every other feature tested — latest_pop_value (r=-0.261,
p=0.046, n=59), time_since_peak (r=0.252, p=0.107), trend_volatility (r=-0.212, p=0.178),
latest_momentum (r=-0.201, p=0.201), embed_similarity (r=-0.177, p=0.180), trend_overall_change
(r=0.061, p=0.702), and trend_max (r=0.0005, p=0.998) — fails to clear the bar, most by a wide margin.
Because none of this group's decision-relevant outcome predictors (latest_pop_value, trend_overall_change,
trend_max) show a real item_age relationship, item age does not meaningfully condition how those
features should be read for this group; the one real item_age link found (trend_min) concerns a feature
that isn't itself a strong outcome predictor here, so it is noted for completeness rather than treated
as an operationally important caveat.

ONE-LINE TAKEAWAY
This group offers only weak evidence overall, but latest_pop_value in the maturing bucket is the single
most useful signal available and should be weighted accordingly given how little else this group's data
supports.


================================================================================
GROUP: medium_popular / decrease
================================================================================

GROUP DEFINITION
Items at medium popularity that declined (n=2,996). Latest popularity value typically 3 (middle 50%:
2-5; full range 2-53). Item age typically 9 months (middle 50%: 2-20). The trend's low point typically
sits at 0 (middle 50%: 0-0; up to 53) and its high point typically at 4 (middle 50%: 3-7; up to 164).
Volatility averages 1.22 (middle 50%: 0.886-1.87; up to 63.3), with a net change of +2 across the
trend. The peak typically occurred 1 month before the latest observation (middle 50%: 0-5). Momentum
typically reads 0.405 (middle 50%: 0-1.1; full range -1.67 to 3), based on 2,519 of the 2,996 items —
477 had no momentum value due to a single trend point. Historically, items reaching this outcome
changed by -1 in popularity value from their pre-outcome value to the final observed value (middle
50%: -3 to -1; full range -50 to -1) — this describes labeled training items and is not computable for
a new item. None of the 2,996 items were debut items; 477 (16%) had only a single real trend point.

DATA RELIABILITY NOTE
This group is large and well-powered overall (n=2,996), with a solid maturing sub-population (2,046)
and reasonably sized recent_multi_point (473) and recent_single_point (477) sub-populations. The
feature-vs-outcome correlations below are each computed on the full medium_popular sample sharing that
bucket (2,120 / 2,341 / 10,471), which is larger still, so those estimates are highly reliable
throughout.

KEY FEATURE-OUTCOME RELATIONSHIPS
In the single-point bucket, latest_pop_value is an extremely strong signal (r=0.751, p<0.001, n=2,120)
— by far the dominant feature in this bucket — while embed_similarity contributes only a very small,
marginally significant signal in the opposite direction (r=-0.057, p=0.0089).
In recent_multi_point, latest_pop_value remains dominant and even stronger (r=0.761, p<0.001, n=2,341),
with trend_max (r=0.589, p=1.4e-218) and trend_min (r=0.573, p=1.5e-204) close behind, time_since_peak
a strong negative signal (r=-0.550, p=2.1e-185: a more recent peak works against this decline
outcome), trend_overall_change strong (r=0.472, p=1.9e-130), trend_volatility strong (r=0.443,
p=3.4e-113), and latest_momentum moderate (r=0.383, p=1.2e-82). item_age is also a real, if smaller,
signal here (r=-0.125, p=1.5e-9 — younger items are modestly more likely to land in this decline
outcome), and embed_similarity is not a real signal (r=-0.002, p=0.92).
In maturing, latest_pop_value again leads (r=0.680, p<0.001, n=10,471), with trend_overall_change
close behind (r=0.594, p<0.001), then latest_momentum (r=0.380, p<0.001), time_since_peak (r=-0.359,
p=1.4e-315), trend_max (r=0.341, p=4.9e-283) and trend_volatility (r=0.297, p=2.2e-212) all
substantial, and trend_min a weaker but real signal (r=0.117, p=4.9e-33). item_age reaches significance
here too but only marginally in magnitude (r=0.078, p=1.1e-15 — statistically real given the very large
sample, but small enough to be practically negligible on its own). embed_similarity is not a real
signal (r=-0.009, p=0.37).

ITEM_AGE-LINKED PATTERNS
Pooled across buckets (n=2,519 for trend-derived features, n=2,996 for latest_pop_value and
embed_similarity), item_age shows several real relationships. The strongest is with trend_min
(r=-0.625, p≈0 — older items have a markedly lower trend floor) and time_since_peak (r=0.427, p≈0 —
older items' peaks are further in the past). trend_volatility (r=-0.193, p=1.7e-22),
trend_overall_change (r=0.192, p=2.6e-22), and latest_pop_value (r=-0.178, p=8.9e-23) are all real,
moderate relationships. trend_max reaches the bar only marginally (r=-0.103, p=2.1e-7). embed_similarity
(r=0.064, p=4.1e-4) is statistically significant but too small in magnitude to be a real relationship
by this document's standard, and latest_momentum (r=0.037, p=0.061) is not significant at all.
Because latest_pop_value, trend_max, and trend_volatility are all top-ranked outcome predictors in this
group's recent_multi_point and maturing buckets, and each carries a real, negative-leaning relationship
with item_age, these should be read with age in mind: older items in this group are systematically
pulled toward lower values on the very features that most drive this outcome, so a lower reading on
those features from an older item carries somewhat less independent weight than the same reading from a
younger one. trend_min's very strong item_age link (r=-0.625) stands out as the dominant pattern in this
group's item_age table and is also directly relevant, since trend_min is itself a leading outcome
predictor in the recent_multi_point bucket.

ONE-LINE TAKEAWAY
Latest popularity value is this group's single strongest and most consistent predictor across every
bucket, with trend_max, trend_min, and trend_volatility as strong secondary signals once real trend
history exists — but all three of those secondary signals should be discounted somewhat for older
items, since age itself pulls them in the same direction as the outcome.


================================================================================
GROUP: medium_popular / increase
================================================================================

GROUP DEFINITION
Items at medium popularity that increased (n=8,251 non-debut items; 16,424 including debut items — see
the separate debut discussion below). Latest popularity value typically 0 (middle 50%: 0-1; full range
0-4). Item age typically 9 months (middle 50%: 4-18). The trend's low point typically sits at 0 (middle
50%: 0-0; up to 3) and its high point typically at 2 (middle 50%: 1-3; up to 164). Volatility averages
0.634 (middle 50%: 0.471-0.97; up to 61.1), with a net change of -1 across the trend. The peak typically
occurred 5 months before the latest observation (middle 50%: 2-10). Momentum typically reads 0 (middle
50%: -0.693 to 0; full range -3 to 1.61), based on 7,731 of the 8,251 non-debut items — 520 had no
momentum value due to a single trend point. Historically, items reaching this outcome changed by +1 in
popularity value from their pre-outcome value to the final observed value (middle 50%: +1 to +2; full
range +1 to +5) — this describes labeled training items and is not computable for a new item. Of the
16,424 total items reaching this outcome, 8,173 (50%) were debut items with no trend history at all;
of the 8,251 non-debut items, 520 (6%) had only a single real trend point.

DATA RELIABILITY NOTE
This is the largest group in the dataset by non-debut member count and, including debut items, the
largest overall. Every correlation below rests on a very large sample (2,120 to 10,471), so reliability
is high throughout for the non-debut portion. Note the striking composition fact that exactly half of
all items historically reaching this outcome were debut items with zero trend history — this group is
unusual in having its membership split almost evenly between "grew from an established but low
baseline" and "appeared from nothing," and the discussion below (outside the debut subpopulation) covers
only the established-baseline half.

KEY FEATURE-OUTCOME RELATIONSHIPS
In the single-point bucket, latest_pop_value is the only real signal, and it is a moderate one
(r=-0.189, p=1.6e-18, n=2,120: a lower current value favors this outcome, consistent with a
low-popularity item having more room to grow). embed_similarity shows no real relationship (r=-0.016,
p=0.46).
In recent_multi_point, latest_pop_value becomes an extremely strong signal (r=-0.731, p<0.001, n=2,341)
— the standout feature in this bucket — with trend_min (r=-0.540, p=2.3e-177), trend_overall_change
(r=-0.452, p=1.9e-118), latest_momentum (r=-0.444, p=1.5e-113), trend_max (r=-0.442, p=1.3e-112), and
time_since_peak (r=0.421, p=2.7e-101) all substantial and mutually consistent in pointing the same way.
trend_volatility is a moderate secondary signal (r=-0.258, p=8.6e-37). item_age reaches significance but
only weakly (r=0.077, p=1.7e-4 — real given the sample size, but small), and embed_similarity is not a
real signal (r=0.032, p=0.12).
In maturing, latest_pop_value again dominates (r=-0.717, p<0.001, n=10,471), with trend_overall_change
close behind (r=-0.581, p<0.001), then latest_momentum (r=-0.456, p<0.001), trend_max (r=-0.277,
p=5.2e-184), time_since_peak (r=0.267, p=9.3e-171), and trend_volatility (r=-0.237, p=1.3e-133) all
substantial, and trend_min a weaker but real signal (r=-0.122, p=6.4e-36). item_age is statistically
significant but small (r=-0.074, p=2.8e-14 — again, real given the huge sample but too small to be
practically meaningful on its own), and embed_similarity shows no real relationship (r=0.001, p=0.92).

ITEM_AGE-LINKED PATTERNS
Pooled across buckets (n=7,731 for trend-derived features, n=8,251 for latest_pop_value and
embed_similarity), the strongest item_age relationship by far is with time_since_peak (r=0.648, p≈0 —
older items' peaks sit much further in the past). trend_max (r=0.262, p=3.8e-121) and trend_min
(r=-0.254, p=4.9e-114) are both real, moderate relationships in opposite directions, and
trend_overall_change is a real, weaker relationship (r=0.163, p=5.1e-47). latest_pop_value reaches the
bar only marginally (r=-0.106, p=4.2e-22). trend_volatility (r=0.057, p=5.4e-7), latest_momentum

================================================================================
DEBUT ITEMS: A STRUCTURALLY SEPARATE POPULATION (spans multiple groups)
================================================================================

WHY THIS IS HANDLED SEPARATELY
Debut items — items with item_age fixed at exactly -1, meaning no historical trend point exists for
them at all — cannot be analyzed with the standard per-group, per-bucket breakdown used above. Every
trend-derived feature (trend_min, trend_max, trend_volatility, trend_overall_change, time_since_peak,
latest_momentum) is undefined by definition for a debut item, not merely weak or untested, and item_age
itself is a fixed constant (-1) for every debut item, so it has zero variance within this population and
cannot be correlated against anything. This is confirmed directly in the data: the one correlation test
available across all debut items in the source material — item_age against embed_similarity — returns
an undefined (NaN) result (n=8,633), precisely because item_age cannot vary within this population.
embed_similarity itself is presumably still computable for a debut item, since it does not depend on
trend history, but no evidence was supplied testing its relationship to the outcome for debut items
specifically, so no claim is made about it here.

COMPOSITION AND REACHABLE OUTCOMES
Across the entire dataset, debut items appear as members of exactly two of the eight groups covered
above: high_popular / increase (460 debut items, 30% of that group's 1,510 total members) and
medium_popular / increase (8,173 debut items, fully half of that group's 16,424 total members). Every
other group examined in this document — high_popular / decrease, high_popular / stable, medium_popular /
decrease, medium_popular / stable, zero_popular / decrease, and zero_popular / stable — explicitly
reports zero debut members, with no exceptions, across a combined population of well over 40,000
non-debut items in those six groups. In other words, in every case observed in this data, a debut item
that reached a labeled outcome reached an "increase" outcome, and never a "decrease" or "stable"
outcome.
This pattern is also consistent with a structural, not merely empirical, explanation: "decrease" and
"stable" are both defined relative to a prior observed value that the item must already have, and a
debut item has no prior value to decrease from or stay stable relative to — only "increase," read as
emerging from a null baseline, is coherent for an item with no history yet. Given both the complete
absence of any counterexample in the data and this structural reasoning, decrease and stable outcomes
should be treated as effectively unreachable for a debut query item, while increase (specifically within
either the high_popular or medium_popular clusters, since no debut members were reported in the
zero_popular clusters in this evidence either) is the only outcome category debut items were ever
observed to reach.

ONE-LINE TAKEAWAY
For a debut query item with no trend history at all, no trend-derived feature can be computed or should
be requested; the only usable evidence is that, historically, every such item that reached a labeled
outcome reached an increase outcome, never a decrease or stable one.
